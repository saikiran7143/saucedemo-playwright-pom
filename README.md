# SauceDemo UI Test Automation Framework
End-to-end UI automation framework built with **Python**, **Playwright**, and **Pytest** using the **Page Object Model (POM)** design pattern.

## Key Highlights
- **POM Architecture:** Separates UI locators/actions (`pages/`) from test cases (`tests/`).
- **Automated Scenarios:** Valid login, locked-out user error validation, and end-to-end cart verification.
- **Reporting:** Generates standalone HTML execution reports using `pytest-html`.
